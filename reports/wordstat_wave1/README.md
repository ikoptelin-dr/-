# Вордстат, волна 1: список масок для ручной проверки

Версия списка 0.1.0. Всего масок: **423**: ярус A — 21, B — 22, C — 380.
Частот в этом файле нет: их снимаете вы. Основа списка — 21 кластер из отчёта `reports/ru_market_2026-11/` и формулировки людей с форумов.

## Как снимать (по ярусам — чтобы не утонуть)

1. Откройте wordstat.yandex.ru и войдите в аккаунт Яндекса.
2. **Ярус A — ★ главные** (`masks_A_star.txt`). По каждой маске:
   - **базовая** частота: `маска` как есть;
   - **фразовая**: `"маска"` в кавычках;
   - **точная**: из файла `masks_A_star_exact.txt` (вид `"!слово !слово"`, предлоги с `+`);
   - регион «Россия», затем ваш регион;
   - скриншот вкладки «Динамика» (сезонность);
   - из левой колонки «Что искали со словом…» скопируйте все хвосты с частотой от 10; если частота маски меньше 20 — хвосты не нужны.
3. **Ярус B — широкие** (`masks_B_broad.txt`): базовая частота по России и вся левая колонка.
4. **Ярус C — остальное** (`masks_C_rest.txt`): одна базовая частота по России. Если фраза уже попала в левую колонку A или B — пропустите её и поставьте отметку в шаблоне.
5. Если у Вордстата есть кнопка выгрузки («Скачать», CSV/XLSX), используйте её вместо копирования.
6. Записывайте в `wordstat_template.csv`, колонки:
   - `base_russia` — базовая, Россия;
   - `phrase_russia` — фразовая, Россия;
   - `exact_russia` — точная, Россия;
   - `base_region` — базовая, ваш регион;
   - `exact_region` — точная, ваш регион;
   - `tails_copied` — хвосты скопированы (да/нет).

   Хвосты из левой колонки присылайте отдельными файлами: одна маска — один файл, или всё в одном CSV `фраза;частота;маска`.

Время [Гипотеза]: A — около 1–1,5 ч, B — около 1–1,5 ч, C — 2–3 ч. Можно прислать A и B, а C — позже.

## Операторы Вордстата

| Оператор | Что делает | Пример |
|---|---|---|
| `"..."` | только эти слова, без хвостов | `"ботокс лоб"` |
| `!` | точная форма слова | `!акнекутан` |
| `+` | учитывать предлог или союз | `+после !ботокса` |
| `-слово` | исключить слово | `косметолог -работа -вакансии` |
| `[...]` | фиксированный порядок слов | `[ретинол для лица]` |
| `(а\|б)` | варианты | `(акнекутан\|роаккутан) отзывы` |

Минус-слова для потребительских масок: `-вакансии`, `-работа`, `-зарплата`, `-курсы`, `-обучение`, `-скачать`, `-приказ`, `-мкб`, `-реферат`, `-презентация`.
Для масок Proba Pro не исключайте «курсы» и «обучение» — это целевое. Исключайте: `-вакансии`, `-зарплата`, `-скачать`, `-реферат`, `-презентация`, `-рядом`, `-отзывы пациентов`.
