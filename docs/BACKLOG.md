# Backlog MVP Proba Intelligence Engine

Версия: 0.1.0 · 2 ноября 2026 года · решения и вопросы — в [DECISIONS.md](DECISIONS.md).

MVP: тема → научные источники → карта утверждений → черновик → человеческая медицинская рецензия → подтверждение publisher → публикация в одном канале. Косметология, русский язык, профессиональная аудитория.

Статусы задач: **выполнено и проверено** · **не начато** · **заблокировано (Q-…)**. Сейчас ни одна функция приложения не реализована.

Правило готовности для каждой задачи, кроме перечисленного в ней: код и тесты в репозитории; тесты проходят командой из раздела «Воспроизведение»; без сетевых вызовов и API-ключей, если задача не помечена иначе; ограничения записаны в описании коммита и в DECISIONS.md при необходимости.

Этапы идут последовательно и соответствуют шагам 2–8 `START_HERE.md`. Следующий этап не начинается, пока не пройдена контрольная точка предыдущего.

|---|---|---|---|

## Воспроизведение (то, что работает сейчас)

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-validation.txt
.venv/bin/python scripts/validate.py
sha256sum -c MANIFEST.sha256
```

Ожидаемо: `validate.py` печатает `OK: 4 схемы, 4 примера, 6 негативных проверок…`; `sha256sum` сообщает 36 OK и отсутствие `.env.example`, `.gitignore`.
