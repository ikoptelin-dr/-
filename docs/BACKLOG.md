# Backlog Proba Intelligence Engine

Версия 0.2.0 от 2 ноября 2026 года. Порядок задан владельцем, см. D-021 и `docs/13_DEMAND_PIPELINE.md`. Решения и вопросы — в [DECISIONS.md](DECISIONS.md).

Статусы задач:
- **сделано и проверено** — есть код, тесты проходят, результат на реальных данных;
- **сделано, не проверено вживую** — код и тесты на подменённом транспорте; против живой площадки не запускалось;
- **не начато**;
- **заблокировано (Q-…)**.

Воспроизведение — в конце файла.

## Этап D1. Источники спроса и первый сбор

| ID | Задача | Критерии готовности | Статус |
|---|---|---|---|
| D1-01 | Реестр площадок `config/sources.yaml` | у каждой площадки есть язык, аудитория, данные, способ доступа, ограничения, подтверждённая стоимость или null, приоритет, степень подтверждения сведений | сделано и проверено (18 площадок; сведения о X/Threads частично по сторонним источникам) |
| D1-02 | Первый проход на реальных обсуждениях | ≥100 реальных обсуждений; у каждого записаны происхождение, язык, дата сбора; заблокированные источники помечены | сделано и проверено: 241 ссылка → 231 запись → 122 сигнала спроса (цель была до 300) |
| D1-03 | Хранилище без дублей, контрольные точки, ограничение частоты, повторы | повторный импорт даёт 0 новых записей; прерванный сбор продолжается с той же страницы; 429/Retry-After и 403 обрабатываются | сделано и проверено тестами |
| D1-04 | Адаптеры Stack Exchange, Reddit (OAuth), Bluesky, RSS | парсинг, пагинация, отказ до сети без ключей | сделано, не проверено вживую — заблокировано (Q-14) |
| D1-05 | Живой сбор 2–3 источников, до 300 обсуждений с текстами, датами и реакциями | ≥2 источника со статусом ok; отчёт о фактическом объёме | заблокировано (Q-14; для Reddit — ключ приложения) |
| D1-06 | Русскоязычные социальные источники: VK API, профессиональные каналы и чаты Telegram | проверены условия; есть адаптер или явный отказ | не начато (нужны токены и согласие администраторов чатов) |
| D1-07 | Загрузка текстов форумов там, где это разрешено | проверены условия площадки; хранится только разрешённое извлечение | заблокировано (Q-18) |
| D1-08 | Следующие языки | решение по данным | предложение: испанский (Doctoralia — вопросы врачам), португальский (Бразилия, в выдаче есть рынок SPF для мелазмы); немецкая выдача почти целиком магазинная |
