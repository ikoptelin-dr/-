# Лизаты, бетулин и экспорт

Статус: проект требований 0.1.0; функциональность предстоит реализовать.


Это будущий исследовательский трек после подтверждения MVP; в пакете нет готового досье, регистрации продукта или доказанной коммерческой эффективности. Лизаты и бетулин рассматриваются как направления исследования, без утверждений о лечебных свойствах.

Для каждого кандидата нужны точная идентичность и состав, происхождение, способ получения, спецификация, аналитические методы, стабильность, сведения о партии, данные безопасности, права на технологию и ограничения использования. Для лизатов особенно важно сохранять конкретный штамм/смесь и процесс; для бетулина — форму, чистоту и состав. Данные не переносятся автоматически между материалами.

Досье строится по матрице «заявление → источник → применимость → пробел → ответственный эксперт». Включаются отрицательные результаты и конфликтующие данные. Отдельно оцениваются производственная воспроизводимость, масштабирование, стоимость партии, потенциальные покупатели и IP. Научная перспективность не означает разрешение на рекламу или продажу.

Этапы: кандидат → проверка идентичности/IP → карта доказательств → оценка пробелов → план исследований → оценка производства → решение о коммерческом пилоте. На каждом этапе возможен отказ. Услуга подготовки досье не гарантирует регистрацию или контракт.

Экспорт начинается с выбора конкретной страны, категории продукта, назначения и заявлений. Затем местный профильный специалист проверяет классификацию, требования к данным, маркировке, импорту и договорам по актуальным официальным источникам. Этот документ не задаёт универсальные юридические требования.

Условие начала: устойчивый контент-пилот, отдельный бюджет, ответственный научный руководитель и владелец IP. Первое расширение — один кандидат и один рынок, без автоматической рассылки коммерческих предложений и без обещания финансовой доходности.
