# Данные и контракты

Статус: проект требований 0.1.0; функциональность предстоит реализовать.


Четыре публичных контракта версии 0.1.0:
- topic.schema.json: редакционное задание, специальность, вопрос, аудитория, критерии и статус.
- source.schema.json: библиография, доступ, проверка, статус отзыва и ограничения.
- article.schema.json: версия текста, утверждения, ссылки, раскрытия, хеш, состояние и публикационные сведения.
- review.schema.json: человеческое решение по точной версии и хешу, чек-лист и срок действия.

Идентификаторы — непустые строки; UUID допустимы, но не обязательны. Время — RFC 3339 с часовым поясом. Использовать Draft 2020-12 с проверкой format: иначе date-time/uri могут не проверяться. additionalProperties=false защищает от случайного расширения контрактов.

Связи: topic 1:N article versions; article.claims N:M sources; review N:1 article version. Уникальны (article.id, article.version), source.id, review.id. source_ids в статье должны равняться объединению source_ids утверждений. Источник каждой ссылки должен существовать. При удалении источника опубликованная история не разрушается.

review_id обязателен для approved/published. publication обязателен для published и содержит URL, время и publisher_id. Эти поля — необходимые структурные условия, но недостаточное доказательство разрешённого выпуска.

Сервис проверяет существование связей, совпадение article_id/version/hash, непросроченность одобрения, checklist=true, отсутствие blocking_issues, компетенцию врача, независимость publisher, актуальность источников и разрешённость перехода. JSON Schema не умеет удостоверять личность, проверять БД, пересчитывать хеш и сравнивать срок с текущим временем.

Внутренние сущности будущей реализации: User, Role, Run, AuditEvent, PublicationAttempt, SearchLog, MetricSnapshot. Они не имеют отдельных JSON Schema в этом пакете. Company, Ingredient, EvidenceDossier, ExportProject — будущие сущности; их не следует создавать как фиктивно работающие модули MVP.

Все examples содержат is_synthetic=true. Продакшн должен отвергать синтетические материалы для выпуска; примеры не подтверждают никакую клиническую пользу.
