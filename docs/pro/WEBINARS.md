## Порядок запуска

```
Месяц 2–3   №1 «Это не акне» — главная сила врача, нет конфликта со спонсорами
Месяц 3–4   №2 «После процедуры» + памятки — мост к клиникам и к пациентам
Месяц 4–5   №3 или №4 — по результатам опроса косметологов
Месяц 5–6   №5 «Оценка линии» — открывает клуб Proba Pro
Месяц 6+    №6 «Новые препараты» — премиум для врачей
```

## Структура любого вебинара (90 минут)

1. **Случай из практики** (5 мин) — зачем это нужно в кабинете.
2. **Механизм простыми словами** (20 мин) — фундаментальная наука: почему так происходит.
3. **Как распознать / что делать** (30 мин) — признаки, алгоритм, фото.
4. **Что говорить клиенту** (10 мин) — готовые фразы.
5. **Граница: когда к врачу** (10 мин).
6. **Вопросы** (15 мин).

**Раздатка:** шпаргалка на 1 страницу + список источников. **Сертификат участия.** Запись — участникам.
