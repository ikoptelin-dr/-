# Карта сайта Proba (версия 0.1, 5 ноября 2026)

Основа: стратегия `docs/STRATEGY_6M.md`, выводы аналитика `docs/ANALYST_FINDINGS_2026-11.md`, Вордстат и форумы.

**Принцип.** Сайт — дом профессионалов (Proba Pro) и научная база. Раздел «Для всех» — небольшой, растёт из тех же досье. Заголовки в разделе «Для всех» — словами людей из Вордстата; в Pro — языком практики.

**Обозначения.** **MVP** — нужно к запуску (месяц 2–3). **Позже** — по мере появления контента и денег. ⚕ — страница с медицинскими утверждениями: публикуется только после рецензии.

## Сквозные элементы на всех страницах

- шапка: «Для специалистов» | «Для всех» | «Вебинары» | «О проекте»;
- подвал: Telegram Proba Pro, Telegram «Proba», правовые страницы, «Реклама и независимость»;
- у каждого материала ⚕: блок «Проверено» (рецензент, дата, версия), список источников, оговорка;
- форма «получить в Telegram» (памятки, шпаргалки, гайды) → бот.
