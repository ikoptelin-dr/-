# Фундаментальная наука о коже: список для чтения

Подборка для авторских постов и видео. Собрано 2026-11-02 через Consensus, прочитано **только по аннотациям**.

Пометка «на ком» обязательна в любом посте:
- **люди** — исследование на людях;
- **мыши** — на животных;
- **клетки** — культура клеток или модель кожи;
- **обзор** — сводка других работ.

Результат на мышах или клетках нельзя подавать как «доказано для человека».

Крючки — идеи подачи для вас, а не готовые утверждения.
