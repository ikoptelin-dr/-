# Статьи (черновики)

Статус всех статей: **черновик, медицинская рецензия не проводилась**. Источники найдены через Consensus и прочитаны **только по аннотациям**. Перед публикацией их нужно сверить по полным текстам, после этого статью проверяет врач.

Фирменная структура каждой статьи:
1. Плашка статуса.
2. Заголовок-вопрос из реального спроса.
3. «Коротко» — три пункта.
4. «Что спрашивают люди» — по нашим кластерам.
5. «Что говорят исследования» — каждая фраза со ссылкой.
6. «Чего наука пока не знает» — пробелы и противоречия.
7. «Что это значит на практике» — общая информация и когда идти к врачу.
8. Источники и список для рецензента.
