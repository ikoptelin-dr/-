# START HERE — последовательная работа с Claude Code

Архив содержит стартовые требования, а не готовый продукт. Распакуйте папку в корень репозитория, откройте её в Claude Code и выполняйте задания ниже по одному. Не передавайте всю последовательность как команду на бесконтрольную публикацию.

Перед работой: создайте отдельную ветку; проверьте совпадающие файлы; не добавляйте .env в git. Для локальной проверки нужны Python 3.10+ и зависимости requirements-validation.txt. Команды установки относятся только к валидатору, не запускают приложение:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-validation.txt
.venv/bin/python scripts/validate.py
```

После каждого шага попросите показать изменённые файлы, проведённые проверки и ограничения. Если предыдущая контрольная точка не пройдена, устраните проблему до зависимых шагов. Внешние сервисы, бюджет и реальные публикации включаются только после выбора владельцем; локальную разработку продолжайте с тестовыми адаптерами.

Зафиксируй нерешённые бюджет, CMS, хостинг и рецензента. Не внедряй пока внешние интеграции.


Контрольная точка: Есть конкретные задачи с критериями приёмки и явно перечисленные неизвестные.
