# Proba Intelligence Engine
Стартовый пакет требований и контрактов, версия 0.1.0, 2 ноября 2026 года.

**Статус: проектирование.** Здесь нет работающего приложения, сервера, базы данных, интеграции с CMS или настроенных LLM. Есть документация, восемь системных промптов, четыре JSON Schema, конфигурационные шаблоны и синтетические примеры. Конфигурация сама по себе ничего не запускает.

Первый продукт — доказательный контент-конвейер для профессиональной аудитории косметологии с обязательным человеческим медицинским рецензированием. Система помогает готовить материалы, но не диагностирует, не назначает лечение и не заменяет специалиста.

## С чего начать
1. Распакуйте содержимое папки `proba-intelligence-starter/` в корень нового репозитория. В существующем репозитории сначала сравните совпадающие файлы.
2. Прочитайте [START_HERE.md](START_HERE.md) и [CLAUDE.md](CLAUDE.md).
3. Передавайте Claude Code промпты из START_HERE по одному, проверяя критерии готовности каждого этапа.
4. Сохраните решения о бюджете, CMS и рецензенте до подключения внешних сервисов. Пустые ключи в `.env.example` не являются рабочими настройками.

## Состав
- `docs/01_VISION.md` — `docs/12_ROADMAP.md`: продукт, доказательность, архитектура и этапы.
- `prompts/`: восемь ролей; роли агентов не равны восьми отдельным сервисам.
- `schemas/`: тема, источник, материал и рецензия; JSON Schema Draft 2020-12.
- `config/specialties.yaml`, `config/models.yaml`: проектная конфигурация с отключёнными внешними вызовами.
- `examples/`: синтетические объекты для проверки контрактов, не медицинские публикации.
- `scripts/validate.py`: работающая локальная проверка контрактов и примеров, не приложение.
- `requirements-validation.txt`: зависимости только для проверки стартового пакета.

Проверка пакета: создайте Python-окружение, установите `pip install -r requirements-validation.txt`, выполните `python scripts/validate.py`. Для проверки не нужны API-ключи и сетевые вызовы после установки зависимостей.

Далее: дерматология и гинекология; затем досье лизатов и бетулина, коммерциализация и экспорт. Сроки и выручка не обещаются. DeepSeek Super-Agent — экспериментальная опция, не продакшн; интеграция не реализована, наличие и возможности продукта нужно проверить по официальным источникам отдельно.
