# Для мам

Продуктовая проверка проекта для молодых мам Новосибирска (команда НГУ). Это не код продукта, а реестр доказательств, замеры и документы решений.

Статус: **проект**. Реестр, исследования R01–R03 и вайтпейпер готовы. Модель на 35 из 45 параметрах — синтетика (по указанию владельца); решение «идём» принимается только по данным пилота.

| путь | что это |
|---|---|
| `10-whitepaper.md` | **вайтпейпер: решение, продукт, каналы, деньги, пилот на 8 недель** |
| `10-pilot-preregistration.md` | пороги «идём / меняем / закрываем» — коммитится до старта пилота |
| `10-model.csv`, `scripts/model_mc.py`, `10-tornado.png` | модель с диапазонами, Монте-Карло, торнадо |
| `10-competitors-prices.csv` | цены конкурентов из снимка выдачи |
| `10-legal-checklist.md` | модель денег → норма → можно / нельзя / нужно заключение |
| `10-interviews/` | анкета, гайды, гипотезы (интервью не проведены) |
| `00-evidence-ledger.md` | реестр: каждое утверждение помечено `ФАКТ`, `ЗАМЕР` или `ДОПУЩЕНИЕ` |
| `inputs/` | файлы, присланные владельцем 2026-11-08, без изменений; суммы в `SHA256SUMS` |
| `inputs/owner-answers-2026-11-08.md` | ответы владельца дословно |
| `scripts/ledger_counts.py` | пересчитывает все `ФАКТ`ы реестра из `inputs/` |
| `scripts/make_wordstat_keys.py` | собирает список фраз для Wordstat и Директа, сверяя их с `all.jsonl` |
| `zamery/z01-night-title-precision.csv` | разметка тем под ночными экранами по заголовкам |
| `zamery/z02-wordstat-keys.csv` | 71 фраза для Wordstat и Директа, колонки для частотности пустые |
| `zamery/z03-direct-paste.txt` | те же 71 фраза без запятых — вставлять в «Прогноз бюджета» Директа |
| `inputs/direct/*.xls` | выгрузки прогноза Директа как есть |
| `scripts/analyze_direct.py` | анализ выгрузок Директа → `zamery/z04-direct-analysis.csv` |
| `research/R01-direct-prompt.md` | протокол исследования выгрузок Директа (вопросы и пороги) |
| `research/R01-direct-results.md` | результаты: спрос, цена клика, курсы, клиники, форум против поиска, паблик |
| `research/R02-publics-method.md` | методика поиска и выгрузки мамских пабликов ВК и Telegram, пороги П1–П4 |
| `scripts/publics/` | сборщики ВК и Telegram (не проверены на живом API), классификатор тем постов (`--selftest`) |
| `zamery/z20-publics-template.csv` | шаблон для ручного прохода по пабликам |
| `research/R03-serp-results.md` | выдача Яндекса по 71 запросу: Алиса, кто в топ-10, Комаровский, местные, курсы |
| `scripts/parse_serp.py`, `analyze_serp.py`, `serp_domain_types.py` | разбор выдачи → `zamery/z12-*` |
| `inputs/external-sources.md` | Росстат: население и рождаемость НСО |
| `scripts/parse_direct_forecast.py` | собирает все выгрузки в `zamery/z03-direct-forecast.csv` (нужен `pip install xlrd`) |

Проверка:

```bash
python3 -I dlya-mam/scripts/ledger_counts.py
python3 -I dlya-mam/scripts/make_wordstat_keys.py
cd dlya-mam/inputs && sha256sum -c SHA256SUMS
```

Внешние модели и платные сервисы не вызываются. Медицинских порогов, дозировок и текстов здесь нет и не будет.

Корневой `CLAUDE.md` относится к другому продукту (косметология). Где жить этому проекту, решает владелец (см. реестр, раздел «Где, по-моему, заказчик ошибается», п. 4).
