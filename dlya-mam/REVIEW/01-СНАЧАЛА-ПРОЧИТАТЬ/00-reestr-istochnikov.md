# Реестр источников для статей

Версия 1, 2026-11-20. В статьях ссылаемся **только** на источники из этого списка. Новый источник сначала вносится сюда со статусом проверки.

Статусы:
- **найден** — существование, номер и год подтверждены поиском 2026-11-20, полный текст редакция не читала;
- **сверить** — по памяти редакции, наличие и реквизиты не подтверждены. В статьях не использовать, пока не проверит редактор или рецензент.

**Правило для всех справок ниже.** Пересказ рекомендаций сделан редакцией по общим сведениям, а не по прочитанному полному тексту. Перед публикацией каждое пороговое значение сверяется с текстом источника. Рецензент проставляет «верно» в таблице утверждений.
