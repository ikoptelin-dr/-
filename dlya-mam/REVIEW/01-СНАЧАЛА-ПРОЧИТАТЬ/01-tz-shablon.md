# Этап 3. Шаблон ТЗ на статью

Заполняется на каждую статью до написания. Пустое поле — статью не пишем.

| поле | что вписать |
|---|---|
| ID и хаб | А1, «Температура» |
| Главный запрос | фраза-голова |
| Намерение | ночь / план / навигация / лечение (лечение — только «что обсудить с врачом») |
| Фразы статьи | голова + хвосты из Wordstat (после этапа 2), с частотами |
| Вопросы для блока «частые вопросы» | из «Люди ищут» (`z12-related.csv`) и `z18-faq-candidates.csv` |
| Разбор топ-10 Яндекса | по каждой позиции: тип сайта, что есть (ответ сразу? когда к врачу? автор-врач? дата?), чего нет. Есть ли ответ Алисы и откуда он взят |
| Наше отличие | что мы даём, чего нет в топе: голос профессора, блок «когда к врачу», конспект, видео |
| План | Ответ (2–3 фразы) → Ситуация мамы → Миф → Правило → Когда к врачу → Что делать → Частые вопросы → Конспект 5–7 пунктов |
| Источник смысла | расшифровка (номер записи, абзац) |
| Источники для сверки | КР Минздрава, ВОЗ, NICE: только те, что назвал профессор, с годом редакции |
| Красные флаги | дословно из расшифровки, одной формулировкой с «Исходом» |
| Запреты | дозировки, названия лекарств как рекомендация, схемы лечения, страх, ругань врачей и форумов, выдуманные цифры и случаи |
| Видео и карточка | номер карточки из `shoot/` |
| Рецензент | педиатр / дерматолог / другой |
| Таблица утверждений | приложена: утверждение → источник → место в тексте → решение рецензента |
