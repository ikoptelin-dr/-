## Правила счёта (для P1)

| бакет | правило |
|---|---|
| вики-заготовки OP | в первом посте есть «полезные данные по теме собраны» |
| мегареды | `len(dialogue_graph) ≥ 400` |
| кулинарные флешмобы | в заголовке или `category_path`: болтушка / обеды и ужины / флешмоб / хвастушк / фото обязательно / фотовыстав / за чашкой чая |
| гомеопатия | «гомеопат» в заголовке, крошках или начале OP |
| рейтинги клиник | заголовок: «контакты и отзывы», «ищем, советуем», «посоветуйте хорош…», «посоветуйте … врач/клиник», «разыскиваются врач», рейтинг клиник/больниц, «стоматологи и стоматологии»; либо крошка «лечебных учреждений» |
| лазер глаз | лазерн… коррекц / ласик / lasik |
| онкология | «онколог» в заголовке, крошках или OP |
| без знака вопроса | нет `?` в заголовке **и** в первых 420 символах OP |

Одна тема может попасть в несколько бакетов. **Жёсткий карантин** = все бакеты кроме «без знака вопроса» (тот слишком широкий, это не выкидывать оптом).

## Вывод для P1

- В жёсткий карантин уходит **173** медицинских и **241** пищевых тем (414 всего), **если** мегареды выкидывать. Это нельзя: среди ≥400 — золото («Желтушка», «Пропадает молоко?», астма). В P1 мегаред = **вес 1**, не drop.
- Drop: вики-OP, флешмобы, гомеопатия, рейтинги клиник, лазер, онкология — **~92 + 181 + 24 + 54 + 3 + 10**, с пересечениями меньше. Ориентир drop без мегаред: медицина ≪ 173, еда ≈ флешмобы (180) + вики.
- Ложные срабатывания «онколог»: гепатит B (t=5657), ГВ после года (t=34279) — в P1 ужесточить (заголовок/крошки, не любое слово в OP).
- Гомеопатия: часть хитов — упоминание в OP чужой темы (t=3163 прививки). P1: якорь на заголовок + крошки, OP только если заголовок про гомеопатию.
- «Без знака вопроса» — **не** drop: 34% медицины и 40% еды.
- Флешмобы почти целиком в еде; рейтинги клиник в еде = 0 (правило не фонит).
