# ТЗ на 300 статей

- `00-index.csv` — список: Tier, место по спросу, хаб, статья, рецензент, спрос, путь к ТЗ, статус.
- `T1/` … `T6/` — по 50 ТЗ на месяц.
- Шаблон заполняется автоматически (`scripts/make_tz.py`): запрос, спрос, сезон, намерение, фразы, частые вопросы мам из Wordstat, источники по хабу, запреты, перелинковка.
- Вручную при написании: разбор топ-10 Яндекса, карточка профессора, таблица утверждений.
- Источники — только из `seo/sources/00-reestr-istochnikov.md`. Справки для Tier 1 — `seo/sources/01-tier1-spravki.md`.
