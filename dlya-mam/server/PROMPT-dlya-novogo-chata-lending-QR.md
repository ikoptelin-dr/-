## Как устроен мой сервер (это уже работает, не ломай)

- Домашний компьютер с **Windows**. Сайт лежит в папке **`D:\med`**.
- Сайт раздаёт **`D:\med\server.js`** — сервер на Node.js без внешних библиотек, запускается через `node.exe` из этой же папки. Слушает **127.0.0.1:8081**.
- Снаружи сайт открывается через **общий Caddy** (он принадлежит другу и обслуживает ещё сайт proba-lab.ru на порту 8080). В Caddyfile уже есть блок:
  ```
  for-mom.ru { encode gzip; reverse_proxy 127.0.0.1:8081 }
  www.for-mom.ru { redir https://for-mom.ru{uri} permanent }
  ```
  **Caddy трогать не нужно.**
- Страницы лежат в **`D:\med\site\`**: `index.html` (лендинг для клиник — лист ожидания, его НЕ заменять), `policy.html`, `404.html`, `robots.txt`.
- Как `server.js` ищет файлы: путь `/abc` → сначала `site\abc` (если это папка — `site\abc\index.html`), если файла нет и у пути нет расширения → `site\abc.html`, иначе `404.html`. Выход за пределы `site\` запрещён.
- API: `POST /api/lead` (заявки → почта/Битрикс24/`leads\leads.jsonl`), `GET /api/health`.
- Управление — `.bat`-файлами в `D:\med`: `ZAPUSTIT-SAJT.bat`, `OSTANOVIT-SAJT.bat`, `1-POSMOTRET-SAJT.bat` (открывает http://localhost:8081), `3-PROVERIT-VSE.bat`. ## Что нужно сделать

Новая страница для мам, куда они попадают по QR-коду с карточки, которую выдают в клинике.

**Адрес:** `https://for-mom.ru/c/?k=МЕТКА_КЛИНИКИ` — например `?k=nsk-klinika-1`.
Файл: **`D:\med\site\c\index.html`** (новая папка `c`). Так не нужно менять `server.js`.
Если параметра `k` нет — метка `direct`.

**Что на странице (сверху вниз):**
1. **Блок «Скорая 103 или 112, если…»** — 5 признаков. Текст возьми ДОСЛОВНО из приложенного файла статьи `D01` (раздел «Когда скорая сейчас») — не сочиняй и не перефразируй медицинский текст.
2. **Лид-магнит:** «Ночная памятка профессоров НГУ: когда скорая, а когда можно до утра» — получить в Telegram.
3. **Зачем помощник:** напоминания о прививках и осмотрах по возрасту ребёнка; ответы ночью — только проверенные врачами.
4. **Одна главная кнопка «Открыть помощника в Telegram»** → `https://t.me/ИМЯ_БОТА?start=МЕТКА_КЛИНИКИ`. Имя бота вынеси в одну константу в начале скрипта (`const BOT = '...'`), я впишу сам. Метку перед вставкой очищай: только латиница, цифры, `-` и `_`, не длиннее 64 символов (это ограничение Telegram для параметра start).
5. **Строка раскрытия:** «Помощник подготовлен научной редакцией — профессора НГУ. Клиника раздаёт его своим пациентам и не влияет на медицинское содержание».
6. Подвал: ссылка на `/policy.html`, строка «ИП ФИО, ИНН — вписать».

**Дизайн:** как у главной `index.html` (приложу) — фон `#FFF9F5`, те же шрифты и цвета. Сначала страница должна хорошо выглядеть на телефоне (мамы открывают с камеры телефона). Без тёмных «плашек» статусов. Лёгкая анимация появления — можно, но всё должно читаться и без неё.

**Технические требования:**
- Один файл `index.html`, всё встроено (CSS и JS внутри). Внешне — максимум Google Fonts. Никаких счётчиков, пикселей, аналитики третьих сторон.
- Страница НИЧЕГО не собирает у мамы: без форм, без телефона, без cookies. Персональные данные появятся только в боте после её согласия.
- `<meta name="robots" content="noindex">` — страница для QR, не для поиска.
- Валидный HTML, работает без JavaScript (кнопка в этом случае ведёт на бота без метки).
