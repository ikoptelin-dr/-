Сайт for-mom.ru — лист ожидания для клиник
============================================

Порядок установки — в инструкции «Как поставить второй сайт», шаги 1–7.

Что в папке:
  1-POSMOTRET-SAJT.bat        запустить и открыть http://localhost:8081
  2-VKLYUCHIT-AVTOZAPUSK.bat  автозапуск при включении (задача «med - sajt»)
  3-PROVERIT-VSE.bat          проверка: сайт, домен, HTTPS, почта
  ZAPUSTIT-SAJT.bat           запустить сайт без браузера
  OSTANOVIT-SAJT.bat          остановить ТОЛЬКО этот сайт (порт 8081)
  nastrojki.txt               домен, порт, почта, Битрикс24
  OBSHCHIJ-CADDY.txt          два блока для Caddyfile друга
  server.js                   сервер сайта и приём заявок
  sluzhebnoe.ps1              служебный скрипт для .bat-файлов
  site\                       страницы сайта (при обновлении заменяется только она)
  node.exe                    СКОПИРОВАТЬ из D:\proba (в архиве его нет)

Куда приходят заявки:
  - на почту из MAIL_TO (нужны SMTP_USER и SMTP_PASS; у Яндекса — пароль приложения);
  - в Битрикс24, если заполнен B24_WEBHOOK;
  - копия в leads\leads.jsonl, если LEAD_LOG=on.
  Если не сработал ни один способ, посетитель увидит «Заявка не отправилась».

Проверка после установки:
  отправьте с телефона тестовую заявку на https://for-mom.ru и убедитесь,
  что письмо пришло. Затем удалите тестовую строку из leads\leads.jsonl.

До показа клиникам заполните в site\policy.html выделенные поля (ИП, ИНН, почта)
и в site\index.html строку «ИП ФИО, ИНН — вписать» внизу страницы.

Журналы работы: logs\server.log и logs\errors.log.
