# Проверка стартового пакета
Дата: 2 ноября 2026 года.

Успешно выполнены: проверка четырёх JSON Schema по Draft 2020-12; валидация четырёх синтетических примеров; шесть негативных тестов; проверка связей и SHA-256 примера; разбор двух YAML; соответствие восьми ролей восьми промптам. Дополнительно проверены комплектность, локальные ссылки README, отсутствие непустых секретов в .env.example, безопасные пути ZIP, CRC и равенство содержимого после распаковки.

При проверке выявлена необходимость зависимости rfc3339-validator для проверки дат; она добавлена в requirements-validation.txt, после чего негативный тест некорректной даты прошёл.

Проверки выполнялись на Python 3.9; для новой разработки рекомендуется Python 3.10+. Установка зависимостей требует сети. Приложение, реальные источники, аутентификация, LLM, CMS и медицинское одобрение не реализованы и не проверялись. Четыре схемы проверяют структуру, а не истинность источников или права человека. Синтетические записи не предназначены для публикации.

MANIFEST.sha256 содержит хеши всех файлов пакета, кроме самого манифеста.
